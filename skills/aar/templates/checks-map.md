# Карта проверок проекта (скилл aar, шаг 6)

Направление - вид вопроса, который проверка задаёт проекту или выводу Claude. Код направления
пишется в поле `угол` журнала разборов. Колонка «чего не ловит» главная: на шаге 6 разбора она
чаще всего и отвечает «нет».

Заполняется только проверками, которые в проекте действительно есть и запускаются. Направление,
которого нет, пишется строкой с пометкой «**Нет проверки**», а не пропускается. Новая строка
добавляется вместе с исполнимой проверкой и одним её настоящим прогоном.

## Направления

| Код | Направление | Где исполняется | Что ловит | Чего не ловит |
|---|---|---|---|---|
| `U` | Модульные тесты | `<папка тестов>`, `<команда>` | | |
| `E` | Сквозные тесты | | | |
| `R` | После выкладки | | | |
| `D` | Выводы по данным (аналитика, база, рекламные кабинеты) | | | |
| `F` | Форма ответа пользователю | | | |
| `T` | Тексты интерфейса и документации | | | |
| `I` | Инструментарий Claude (скрипты, права, окружение) | | | |

## Когда направление обязательно

| Что затронуто | Обязательные направления |
|---|---|
| Любая правка кода | `U E` - `<команда полного прогона>`, до коммита |
| Выкладка | `R` |
| Вывод пользователю по данным | `D` |
| Ответ на просьбу о результате | `F` |
| Текст на экране или в документации | `T` |
